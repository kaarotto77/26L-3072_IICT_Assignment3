
# TechZone - My Mini Store

TechZone is a mini online store that displays different products such as gadgets, accessories and audio devices.
Users can view product prices, availability and ratings, and subscribe to receive updates.

## CSS Precedence

The tagline appears green because inline CSS has the highest priority.
Other paragraphs appear dark red because internal CSS overrides external CSS.
External CSS gives paragraphs a gray colour, but internal CSS overrides it.
